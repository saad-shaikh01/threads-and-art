# Threads & Arts homepage frontend

Standalone local frontend draft. Open index.html in a browser, or serve this directory with `python3 -m http.server 8765`.

Contains responsive HTML/CSS/JavaScript and bundled images. No dependencies or build step. Includes mobile navigation, a thread-drawing hero, service scrolling, portfolio modal, section reveals, counters and reduced-motion support.

Approved figures: serving since 2017, 400+ customers, 50,000+ designs.

The tiger is AI-generated illustrative brand artwork. Portfolio/service images come from the supplied website archive. Live login/service links point to the existing website. The sample CTA opens a prefilled email; no submission or upload backend is implemented. This is a visual frontend draft, not a deployed replacement or complete PHP integration. SEO work is deferred.

Motion update: subtle staggered hero entry, maximum 5px pointer depth, delayed thread tracing and a reversible scroll-driven TA monogram transformation. Transformation uses an illustrative SVG stitch texture, not a real customer sew-out. Reduced-motion mode displays the finished design without a long sticky scroll.
